# Java Course Assignments & Exercises

This repository contains a collection of basic Java applications and practice exercises developed as part of a programming course.

## 📁 Files Included

- **`PokeCRUD.java`**: A console-based Pokémon management application supporting full CRUD operations (Create, Read, Update, Delete) using an `ArrayList`.
- **`Calculator.java`**: A basic calculator program for performing standard mathematical operations.
- **`TemperatureConverter.java`**: A tool for converting temperatures between standard units (e.g., Celsius and Fahrenheit).
- **`Veckodagskoll.java`**: A program designed to evaluate or check days of the week.
- **`listArrayApp.java`**: Exercises focusing on working with arrays and list structures in Java.
- **`Main.java`**: General entry point or runner class.
